# Campfire 開發紀錄 v0 - 2025/01/29

## 遊戲簡介

「雪境營火」是一款 2D 俯視角生存經營遊戲。玩家使用虛擬搖桿控制角色在雪地營區移動，必須透過採集木材維持營火燃燒，否則會因體溫過低而凍死。同時可以釣魚、烹飪、販售來賺取金幣，購買升級提升效率。

---

## 功能清單

- [x] 虛擬搖桿控制（8 方向）
- [x] 角色一步一步移動動畫

- [x] 體溫系統（距離營火越遠下降越快）

- [x] 自動採集系統（靠近區域自動採集）

## 技術實作重點

### 1. 虛擬搖桿

使用觸控/滑鼠事件處理搖桿拖曳：

```typescript
const handleJoystickMove = (e) => {
    const dx = touch.clientX - joystickRef.current.startX;
    const dy = touch.clientY - joystickRef.current.startY;
    const distance = Math.sqrt(dx * dx + dy * dy);
    const clampedDistance = Math.min(distance, MAX_DISTANCE);

    // 超過死區才開始移動
    if (distance > DEAD_ZONE) {
        const degrees = ((Math.atan2(-dy, dx) * 180) / Math.PI + 360) % 360;
        directionRef.current = getDirectionFromAngle(degrees);
    }
};
```

### 2. 一步一步走動

使用 `setInterval` 配合步伐間隔：

```typescript
moveLoopRef.current = setInterval(() => {
    const delta = getMoveDelta(directionRef.current, STEP_DISTANCE);
    // 更新位置
    setPlayerPos(newPos);
    setWalkFrame(f => (f + 1) % 2); // 走動動畫幀
}, STEP_INTERVAL);
```

### 3. 體溫與距離關係

根據與營火的距離計算體溫變化：

```typescript
const calculateTempChange = (pos, fuel) => {
    const distToCampfire = getDistance(pos, POS_CAMPFIRE);

    if (fuel <= 0) return -TEMP_DECAY_NEAR; // 營火熄滅無法取暖

    if (distToCampfire <= TEMP_WARM_RANGE) return TEMP_RECOVER;
    if (distToCampfire < 150) return -TEMP_DECAY_NEAR;
    if (distToCampfire < 250) return -TEMP_DECAY_MID;
    return -TEMP_DECAY_FAR;
};
```

### 4. 使用 Ref 避免閉包問題

遊戲迴圈中使用 `useRef` 追蹤即時狀態：

```typescript
const stateRef = useRef({
    playerPos, temperature, fireFuel, resources, ...
});

// 在 setInterval 中使用
const state = stateRef.current;
state.temperature = newTemp;
setTemperature(newTemp);
```
