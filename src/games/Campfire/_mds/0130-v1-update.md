# Campfire 更新紀錄 v1 - 2025/01/30

## 更新內容

本次更新包含以下修改：

### 1. 顯示各區域作用範圍

**修改原因**：玩家無法直觀判斷何時會觸發砍樹、釣魚、取暖等動作。

**修改方式**：在地圖上以虛線圓圈顯示各區域的交互範圍。

- 營火取暖範圍：橙色半透明圓圈（含填充）
- 森林區：綠色虛線圓
- 冰湖區：藍色虛線圓
- 收銀台：金色虛線圓
- 升級站：灰色虛線圓

---

### 2. 新增營火升級（強化營火）

**修改原因**：原版缺少營火升級機制，取暖範圍固定不變。

**修改方式**：新增第 5 項升級「強化營火」。

| 項目 | 值 |
|------|-----|
| 名稱 | 🔥 強化營火 |
| 價格 | $300 |
| 效果 | 取暖範圍 70px → 120px |

- 取暖範圍視覺圓圈會即時變大
- 升級後收銀台與升級站也在取暖範圍內

---

### 3. 調整地圖佈局

**修改原因**：原版賣場與升級站在同一直線上、距離營火太遠，玩家容易凍死。

**修改方式**：

| 區域 | 修改前 | 修改後 |
|------|--------|--------|
| 營火 | (200, 140) | (200, 160) |
| 收銀台 | (200, 290) 正下方 | (110, 250) 左下方 |
| 升級站 | (200, 390) 更下方 | (290, 250) 右下方 |

佈局從「一條直線」改為「V 字形」：

```
修改前：                修改後：

  🌲       🔥       🧊     🌲       🔥       🧊
           |                   ╱   ╲
           🛒              🛒       🔧
           |
           🔧
```

---

### 4. 先前 bug 修正（v0 → v1 之間的 hotfix）

- 移動系統改為 `setInterval(16ms)` 平滑移動，解決卡頓暴衝
- 新增鍵盤方向鍵 + WASD 控制
- 賣魚、添柴、烹飪邏輯整合到主遊戲循環，解決無法賣魚的問題
- 添柴條件從「燃料 < 50%」改為「燃料未滿」
