# Campfire 更新紀錄 v2 - 2025/01/31

## 更新內容

本次更新為大改版，包含地圖擴展、多棵可耗盡樹木、儲木場、食物置物區、攜帶物品視覺化等系統。

---

### 1. 地圖橫向擴展 + 鏡頭系統

**修改原因**：原地圖 400×450 太小，缺乏探索感。

**修改方式**：地圖寬度擴展為 800px，視口維持 400px，鏡頭水平跟隨玩家。

| 項目 | 修改前 | 修改後 |
|------|--------|--------|
| 地圖寬度 | 400px | 800px |
| 視口寬度 | 400px | 400px（不變） |
| 鏡頭 | 無 | 水平跟隨，CSS translateX |

- 新增 `.world` 容器包覆所有遊戲元素
- `calculateCameraX()` 計算鏡頭偏移，限制在 `[0, MAP_WIDTH - VIEWPORT_WIDTH]`

---

### 2. 多棵可耗盡樹木

**修改原因**：原版只有一個森林區，砍樹沒有消耗感。

**修改方式**：改為 9 棵獨立樹木，每棵可砍伐 10 次後消失。

| 項目 | 值 |
|------|-----|
| 初始樹木 | 9 棵（3 棵在視口左緣，6 棵在畫面外左側） |
| 每棵可砍次數 | 10 次 |
| 砍伐範圍 | 25px（縮小，避免重疊） |
| 樹間最小距離 | 50px |

- 新增 `TreeData` 介面（id, x, y, remainingHarvests）
- 每棵樹下方顯示剩餘砍伐次數進度條
- 砍完後從陣列移除，不會自動生長

---

### 3. 生長加速劑（消耗品）

**修改原因**：樹砍完後需要補充新樹的手段。

**修改方式**：升級站新增消耗品「生長加速劑」。

| 項目 | 值 |
|------|-----|
| 價格 | $50 |
| 效果 | 在隨機有效位置長出一棵新樹 |
| 類型 | 消耗品（可重複購買） |

- `findValidTreePosition()` 隨機找位置，需與其他樹和固定區域保持距離

---

### 4. 木柴儲木場

**修改原因**：背包容量有限，需要暫存木柴的地方。

**修改方式**：營火上方新增方形儲木場。

| 項目 | 值 |
|------|-----|
| 位置 | (400, 90)，營火正上方 |
| 大小 | 60×50px 矩形 |
| 容量 | 20 |
| 存入 | 從左邊進入自動存入 |
| 取出 | 從右邊進入自動取出 |

- 方框設計，虛線邊框 + 棕色底色
- 左右兩側標示「存入 ➡」「⬅ 取出」

---

### 5. 食物置物區

**修改原因**：煮熟的食物直接跳到身上不合理。

**修改方式**：營火下方新增食物置物區，烹飪完成的魚自動放入。

| 項目 | 值 |
|------|-----|
| 位置 | (400, 245)，營火正下方 |
| 大小 | 60×30px 矩形 |
| 存入 | 烹飪完成自動放入（不進玩家背包） |
| 取出 | 從右邊進入全部取出 |

- 橘色虛線邊框，與木柴儲木場做視覺區分
- 顯示 `🍳 N` 表示庫存數量
- 新增 `cookedFishStorage` 狀態 + `foodStorageEntryRef`

---

### 6. 營火燃料緩衝機制

**修改原因**：玩家進入營火區會在短時間內把所有木頭都丟進去。

**修改方式**：新增燃料容量上限，超過顯示上限時不再添柴。

| 項目 | 值 |
|------|-----|
| 實際容量 `FIRE_CAPACITY` | 110 |
| 顯示上限 `FIRE_MAX` | 100 |
| 添柴條件 | 燃料 < 100 時才添加 |
| 顯示 | `Math.min(fireFuel, 100)%` |

- 每次添柴 +20，可衝到 110，等衰減回 100 以下才會再添

---

### 7. 攜帶物品視覺化

**修改原因**：玩家看不出角色身上帶了什麼。

**修改方式**：角色下方顯示攜帶物品的堆疊 emoji。

- 木柴：`🪵🪵🪵`（幾個就幾個 emoji）
- 生魚：`🐟🐟🐟`
- 熟魚：`🍳🍳🍳`
- 使用 `flex-wrap` 自動換行，最大寬度 48px

---

### 8. 收銀台與升級站對調

**修改原因**：調整區域佈局，使動線更合理。

**修改方式**：

| 區域 | 修改前 | 修改後 |
|------|--------|--------|
| 升級站 🔧 | (490, 250) 右側 | (310, 250) 左側 |
| 收銀台 🛒 | (310, 250) 左側 | (490, 250) 右側 |

---

### 9. Bug 修正

#### 體溫條隨角色翻轉

- **問題**：角色面朝左時 `scaleX(-1)` 套用在整個 `.player` div，導致體溫條也跟著反轉
- **修正**：`scaleX(-1)` 改為只套用在 `.player-emoji`，新增基礎 `transform: translate(-50%, -50%)` 置中

#### 置物區外觀

- **問題**：置物區原本用 icon + label 設計，看不出方形邊界和進出方向
- **修正**：改為帶虛線邊框的方框 `.storage-box`，左右兩側標示存取方向
