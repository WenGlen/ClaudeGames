## 遊戲概述

### 簡介

在雪地中生存的經營遊戲。玩家必須採集木材維持營火燃燒，否則會凍死。在確保生存的同時，可以釣魚、烹飪、販售來賺取金幣，逐步升級裝備提升效率。

### 遊戲類型

2D 俯視角 / 生存經營 / 資源管理 / 閒置遊戲

### 核心循環

```
🔥 維持營火（生存核心）
      ↓
🪓 採集木材 → 🎣 釣魚 → 🍳 烹飪 → 💰 販售 → 🔧 升級
```

### MVP 設計原則

此版本使用純 **JavaScript + SCSS** 實作，不使用遊戲框架：

- **DOM-based 渲染**：使用 HTML 元素而非 Canvas
- **CSS 動畫**：利用 SCSS 處理視覺效果
- **計時器驅動**：使用 setInterval 處理遊戲循環
- **簡化操作**：點擊區域觸發行動，無需鍵盤控制

## 核心玩法

### 遊戲目標

1. **生存**：保持營火燃燒，維持體溫不歸零
2. **經營**：透過釣魚販售賺取金幣
3. **升級**：購買升級提升採集效率

### 操作方式

| 操作 | 動作 |
|------|------|
| 點擊「森林區」 | 開始/停止砍樹（獲得木材） |
| 點擊「冰湖區」 | 開始/停止釣魚（獲得生魚） |
| 點擊「營火區」 | 添加木材 / 放入生魚烹飪 |
| 點擊「收銀台」 | 販售熟魚換取金幣 |
| 點擊「升級商店」 | 購買升級 |

### 遊戲規則

1. **營火機制**
   - 營火有燃料值（0-100），持續下降
   - 燃料歸零時營火熄滅
   - 每添加 1 木材 = +20 燃料
   - 營火燃燒時才能烹飪

2. **體溫機制**
   - 玩家有體溫值（0-100）
   - 靠近營火：體溫緩慢回升
   - 離開營火（在森林/冰湖）：體溫持續下降
   - 體溫歸零 = 遊戲結束

3. **資源採集**
   - 森林區：每 1 秒獲得 1 木材
   - 冰湖區：每 1.5 秒獲得 1 生魚
   - 採集時體溫會下降

4. **烹飪機制**
   - 在營火區放入生魚
   - 每條魚需要 3 秒烹飪
   - 營火必須燃燒中才能烹飪

5. **交易機制**
   - 熟魚可以在收銀台販售
   - 每條熟魚 = 10 金幣

### 勝利/失敗條件

- **失敗**：體溫歸零（凍死）
- **目標**：累積金幣、購買升級、生存越久越好

```
                    |                   |
```

|------|------|

| `playing` | 遊戲進行中 |
| `paused` | 遊戲暫停 |

## 技術規格

### 遊戲參數

```typescript
const CONFIG = {
    // 時間設定（毫秒）
    GAME_TICK: 100,           // 遊戲主循環間隔
    CHOP_INTERVAL: 1000,      // 砍樹間隔
    FISH_INTERVAL: 1500,      // 釣魚間隔
```

### 資料結構

```typescript
// 遊戲狀態
type GameStatus = 'idle' | 'playing' | 'paused' | 'gameover';

// 玩家位置/行動
type PlayerLocation = 'campfire' | 'forest' | 'lake' | 'shop';

// 玩家資源
interface Resources {
    wood: number;      // 木材
    rawFish: number;   // 生魚
    cookedFish: number; // 熟魚
    gold: number;      // 金幣
}

// 玩家升級狀態
interface Upgrades {
    axe: boolean;      // 鋼鐵斧
    rod: boolean;      // 高級釣竿
    boots: boolean;    // 保暖靴
    backpack: boolean; // 大背包
}

// 遊戲狀態
interface GameState {
    status: GameStatus;
    temperature: number;       // 體溫 0-100
    fireFuel: number;          // 營火燃料 0-100
    cookingFish: number;       // 正在烹飪的魚數量
    cookingProgress: number;   // 烹飪進度 0-100
    playerLocation: PlayerLocation;
    resources: Resources;
    upgrades: Upgrades;
    survivalTime: number;      // 存活時間（秒）
}
```

### State 清單

| State | 類型 | 說明 |
|-------|------|------|
| `gameStatus` | `GameStatus` | 遊戲狀態 |
| `temperature` | `number` | 玩家體溫 (0-100) |
| `fireFuel` | `number` | 營火燃料 (0-100) |
| `playerLocation` | `PlayerLocation` | 玩家當前位置 |
| `resources` | `Resources` | 資源數量 |
| `upgrades` | `Upgrades` | 升級狀態 |
| `cookingQueue` | `number` | 烹飪中的魚數量 |
| `cookingProgress` | `number` | 當前烹飪進度 |
| `survivalTime` | `number` | 存活時間 |

### Ref 清單

| Ref | 類型 | 用途 |
|-----|------|------|
| `gameLoopRef` | `number` | 主遊戲循環計時器 ID |
| `gatheringRef` | `number` | 採集計時器 ID |
| `cookingRef` | `number` | 烹飪計時器 ID |
| `stateRef` | `GameState` | 即時遊戲狀態 |

## 遊戲平衡建議

### 難度曲線

| 時間 | 挑戰 |
|------|------|
| 0-30s | 熟悉操作，體溫下降慢 |
| 30s-2m | 需要注意營火燃料 |
| 2m+ | 體溫下降加速，需升級生存 |

### 升級優先級建議

1. **保暖靴** - 延長在外時間
2. **鋼鐵斧** - 更快獲得燃料
3. **高級釣竿** - 提高收入
4. **大背包** - 減少來回次數
