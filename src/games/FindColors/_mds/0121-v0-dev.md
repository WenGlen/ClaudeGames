# FindColors 開發紀錄 v0 - 2026/01/21

## 遊戲簡介

「看色」是一款色彩辨識益智遊戲。玩家需要從多個相近色塊中找出與目標顏色完全相同的色塊。隨著關卡推進，選項數量增加、顏色差異縮小，難度逐漸提升。時間即分數，答對獲得時間獎勵，答錯扣 5 秒，時間歸零則遊戲結束。

## 技術實作重點

### 1. 色彩空間轉換與 Delta E 計算

使用 CIE76 Delta E 公式計算色差，確保干擾色與目標色的差異可控：

```typescript
// RGB → XYZ → LAB 轉換
const rgbToLab = (rgb: RGB): LAB => {
    return xyzToLab(rgbToXyz(rgb));
};

// Delta E (CIE76) 計算
const deltaE = (lab1: LAB, lab2: LAB): number => {
    return Math.sqrt(
        Math.pow(lab1.l - lab2.l, 2) +
        Math.pow(lab1.a - lab2.a, 2) +
        Math.pow(lab1.b - lab2.b, 2)
    );
};
```

### 2. 動態色塊尺寸計算

根據容器大小與選項數量自動計算最佳色塊尺寸：

```typescript
const calculateOptionSize = (optionCount: number): number => {
    const cols = Math.ceil(Math.sqrt(optionCount));
    const rows = Math.ceil(optionCount / cols);

    const maxByWidth = (containerWidth - (cols + 1) * gap) / cols;
    const maxByHeight = (containerHeight - (rows + 1) * gap) / rows;

    return Math.max(MIN_SIZE, Math.min(MAX_SIZE, Math.min(maxByWidth, maxByHeight)));
};
```

### 3. 難度遞進機制

- **選項數量**：每 5 關 +2 個（無上限）
- **顏色差異**：隨關卡遞減（20 → 15 → 10 → 5 → 3 → 1）
- **時間獎勵**：每 10 關增加（+10 → +20 → +30...）

### 4. 答錯視覺提示

答錯時不影響繼續作答的提示：
- 時間數字抖動動畫（shake）
- 「-5」飄浮文字動畫（floatUp）
- 錯誤選項紅色邊框脈衝（wrongPulse）

## 遊戲參數

| 參數 | 值 | 說明 |
|------|-----|------|
| `INITIAL_TIME` | 10 | 初始時間（秒） |
| `WRONG_PENALTY` | 5 | 答錯扣時（秒） |
| `INITIAL_OPTIONS` | 4 | 初始選項數量 |
| `OPTIONS_INCREMENT` | 2 | 每次增加數量 |
| `OPTIONS_INCREMENT_INTERVAL` | 5 | 每 N 關增加一次 |
| `BASE_TIME_REWARD` | 10 | 基礎過關獎勵（秒） |
| `REWARD_INCREMENT_INTERVAL` | 10 | 獎勵遞增間隔（每 N 關） |
