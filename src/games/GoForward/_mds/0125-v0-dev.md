# GoForward 開發紀錄 v0 - 2025/01/25

## 遊戲簡介

GoForward 是一款 2D 橫向捲軸平台跳躍遊戲，玩家控制一個方塊主角，透過移動和跳躍穿越隨機生成的平台地形，避開空洞和尖刺障礙物，盡可能往右前進以獲得高分。遊戲採用無盡模式，距離越遠難度越高。

## 技術實作重點

### 1. 物理引擎

採用加速度式移動系統，區分地面和空中狀態：

```typescript
// 地面加速快、空中加速慢
const acceleration = player.isGrounded
    ? CONFIG.GROUND_ACCELERATION  // 0.8
    : CONFIG.AIR_ACCELERATION;    // 0.4

// 摩擦力（僅地面）
if (player.isGrounded && !pressing) {
    player.vx *= CONFIG.FRICTION;  // 0.85
}

// 空氣阻力
player.vx *= CONFIG.AIR_RESISTANCE;  // 0.98
```

這讓跑步跳躍能保持水平速度，比靜止跳躍跳更遠。

### 2. 鏡頭系統

鏡頭只在玩家往右超過閾值時才移動，往左移動時不跟隨：

```typescript
const playerScreenX = player.x - camera.x;
const cameraThreshold = CANVAS_WIDTH * 0.4;

if (playerScreenX > cameraThreshold) {
    camera.x = player.x - cameraThreshold;
}
```

玩家被限制在鏡頭左邊界內，無法退回已捲動的區域。

### 3. 平台生成

使用無限生成機制，當鏡頭接近最後一個平台時動態生成新平台：

- 起始平台較長較平，方便玩家熟悉操作
- 間隙和高度差隨機變化
- 根據距離增加難度（更大間隙、更小平台）
- 自動清除離開畫面的平台以節省記憶體

### 4. 難度曲線

```typescript
const difficultyFactor = Math.min(1, distance / 5000);

// 間隙隨距離增加
const minGap = GAP_MIN_WIDTH + difficultyFactor * 1;
const maxGap = GAP_MAX_WIDTH + difficultyFactor * 2;

// 平台寬度隨距離減小
const minWidth = Math.max(2, PLATFORM_MIN_WIDTH - difficultyFactor * 1);
const maxWidth = Math.max(4, PLATFORM_MAX_WIDTH - difficultyFactor * 3);
```
