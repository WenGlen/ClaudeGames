## 遊戲概述

### 簡介

GoForward 是一款 2D 橫向捲軸平台跳躍遊戲，類似經典的瑪利歐。玩家控制一個方塊主角，透過移動和跳躍穿越由平台組成的地形，避開空洞和障礙物，盡可能往右前進以獲得高分。

### 遊戲類型

動作、平台跳躍、無盡模式

---

## 核心玩法

### 遊戲目標

控制主角方塊不斷往右前進，走得越遠分數越高。

### 操作方式

#### 鍵盤操作

| 按鍵 | 動作 |
|------|------|
| ← / A | 向左移動 |
| → / D | 向右移動 |
| Space / ↑ / W | 跳躍 |
| P / Esc | 暫停/繼續 |

#### 手機操作（觸控）

畫面下方設有虛擬按鈕：
- 左側：← → 方向鍵
- 右側：跳躍按鈕

### 遊戲規則

1. **移動機制**
   - 主角有加速度，按住方向鍵會逐漸加速到最高速度
   - 放開方向鍵後會有慣性，逐漸減速停止
   - 空中可以控制方向，但加速度較地面低

2. **跳躍機制**
   - 只有在地面上才能起跳
   - 跑步時跳躍會保持水平速度，因此能跳更遠
   - 靜止時跳躍只能垂直跳躍

3. **鏡頭機制**
   - 主角最多只能到達畫面水平中心
   - 當主角試圖往右超過中心時，畫面會往左捲動
   - 往左移動時畫面不會捲動
   - 主角無法超出畫面左側邊界

4. **地形生成**
   - 平台由方塊組成，隨機生成
   - 平台之間可能有間隙（空洞）
   - 平台高度會有變化
   - 隨著距離增加，難度漸增（更多空洞、更大跳躍距離）

5. **障礙物**
   - 地面上可能出現障礙物（尖刺）
   - 碰到障礙物會立即死亡

### 勝利/失敗條件

- **勝利**：無（無盡模式，追求高分）
- **失敗**：
  - 掉落至畫面底部
  - 碰觸到障礙物

## 遊戲狀態

```
[idle] --開始--> [playing] --暫停--> [paused]
                    |                   |
                    v                   |
               [gameover] <----繼續-----+
```

| 狀態 | 說明 |
|------|------|
| `idle` | 遊戲尚未開始，顯示開始畫面 |
| `playing` | 遊戲進行中 |
| `paused` | 遊戲暫停 |
| `gameover` | 遊戲結束，顯示結算畫面 |

## 技術規格

### 遊戲參數

```typescript
const CONFIG = {
    // 畫布設定
    CANVAS_WIDTH: 800,
    CANVAS_HEIGHT: 400,

    // 格子大小（地形基本單位）
    TILE_SIZE: 32,

    // 主角設定
    PLAYER_SIZE: 28,               // 主角方塊大小
    PLAYER_COLOR: '#4ecca3',       // 主角顏色

    // 物理設定
    GRAVITY: 0.6,                  // 重力加速度
    JUMP_FORCE: -12,               // 跳躍初速度
    GROUND_ACCELERATION: 0.8,     // 地面加速度
    AIR_ACCELERATION: 0.3,        // 空中加速度
    MAX_SPEED_X: 6,               // 最大水平速度
    FRICTION: 0.85,               // 地面摩擦力（減速係數）
    AIR_RESISTANCE: 0.98,         // 空中阻力

    // 鏡頭設定
    CAMERA_OFFSET_X: 0.5,         // 主角在畫面中的水平位置比例

    // 地形生成設定
    PLATFORM_MIN_WIDTH: 3,        // 平台最小寬度（tile 數）
    PLATFORM_MAX_WIDTH: 8,        // 平台最大寬度
    GAP_MIN_WIDTH: 2,             // 間隙最小寬度
    GAP_MAX_WIDTH: 4,             // 間隙最大寬度
    HEIGHT_VARIATION: 2,          // 高度變化範圍（tile 數）

    // 障礙物設定
    OBSTACLE_CHANCE: 0.1,         // 障礙物出現機率
    OBSTACLE_COLOR: '#e74c3c',    // 障礙物顏色
```

### 資料結構

```typescript
type GameStatus = 'idle' | 'playing' | 'paused' | 'gameover';

/** 玩家狀態 */
interface Player {
    x: number;          // 世界座標 X
    y: number;          // 世界座標 Y
    vx: number;         // 水平速度
    vy: number;         // 垂直速度
    isGrounded: boolean; // 是否在地面上
}

/** 平台 */
interface Platform {
    x: number;          // 世界座標 X（左上角）
    y: number;          // 世界座標 Y（左上角）
    width: number;      // 寬度（像素）
    height: number;     // 高度（像素）
}

/** 障礙物 */
interface Obstacle {
    x: number;          // 世界座標 X
    y: number;          // 世界座標 Y
    width: number;      // 寬度
    height: number;     // 高度
}

/** 輸入狀態 */
interface InputState {
    left: boolean;
    right: boolean;
    jump: boolean;
}

/** 鏡頭 */
interface Camera {
    x: number;          // 鏡頭左邊界的世界座標
}
```

## 物理計算詳解

### 移動更新（每幀）

```
// 地面上
if (isGrounded) {
    if (pressing left/right) {
        vx += direction * GROUND_ACCELERATION
    }
    vx *= FRICTION  // 摩擦力減速
}

// 空中
else {
    if (pressing left/right) {
        vx += direction * AIR_ACCELERATION
    }
    vx *= AIR_RESISTANCE
    vy += GRAVITY  // 重力
}

// 限制最大速度
vx = clamp(vx, -MAX_SPEED_X, MAX_SPEED_X)

// 更新位置
x += vx
y += vy
```

### 碰撞檢測

1. **平台碰撞**：玩家腳底碰到平台頂部時，停止下落並設為 grounded
2. **左邊界**：玩家不能超出鏡頭左邊界
3. **掉落判定**：玩家 Y 座標超過畫布高度
